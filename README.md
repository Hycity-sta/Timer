# Timer (倒计时应用)

基于 Swift & SwiftUI 构建的轻量级原生 macOS 倒计时单窗口应用。

## 规格与标识符规范

- **Bundle Identifier**:
  - Release 版：`com.hycity.timer`
  - Debug 版：`com.hycity.timer.debug`（数据独立隔离）

## 功能特性

- **6 格数字倒计时**：
  - 时（2位）、分（2位）、秒（2位），清晰分隔并带有标签提示。
- **灵活输入与交互**：
  - 点击任意格子可直接键盘输入数字，输入后光标自动跳至下一格。
  - 鼠标悬浮格子时提供上下箭头快速微调（+1 / -1）。
- **运行控制**：
  - **开始 / 暂停 / 继续**：一键控制倒计时。
  - **重置 / 归零**：可一键重置至设定时长或全部归零。
  - **倒计时结束提示**：结束时触发系统提示音与界面提醒。
- **倒计时列表（侧边栏）**：
  - 窗口左侧为可折叠侧边栏（使用工具栏中的系统侧边栏按钮切换），列出所有倒计时项及其设定时长。
  - **空状态启动**：每次启动应用时默认不选中任何倒计时，右侧显示简洁的空状态引导界面；在左侧选择已有倒计时或新建倒计时后才进入倒计时主界面。
  - **新建倒计时**：点击侧边栏顶部的「新建倒计时」按钮（或空界面按钮、快捷键 `⌘N`），即可创建一个名为“未命名倒计时”、初始时长为 `00:00:00` 的倒计时项并自动选中。
  - **自动同步保存**：选中倒计时后，修改时长（键盘输入、上下微调或归零）与重命名均自动实时保存，无需手动点击保存按钮。
  - **切换与管理**：点击侧边栏项即可切换（若当前倒计时正在运行或已暂停，会先弹窗确认是否停止）；右键菜单支持「重命名」「删除」（重命名留空时回退为“未命名倒计时”）；选中后按 Delete 键也可删除（删除当前选中项会停止计时并回到空界面）；支持拖动排序。
- **单窗口**：应用仅允许一个主窗口（`⌘N` 用于在当前窗口内新建倒计时，不支持多开窗口）。

## 运行与开发

### 方式 1：打包并运行 macOS 原生应用（推荐）
```bash
# 构建 Release 版本 (输出 dist/Timer.app，系统自动本地化为“倒计时”)
./build_app.sh release
open dist/Timer.app

# 构建 Debug 版本 (输出 dist/Timer-Debug.app，系统自动本地化为“倒计时 (Debug)”，数据与 Release 完全隔离)
./build_app.sh debug
open dist/Timer-Debug.app

# 同时构建 Release 与 Debug 版本
./build_app.sh all
```

### 方式 2：终端命令行直接运行
```bash
swift run
```

### 方式 3：使用 Xcode 打开
```bash
xed .
```
或者在 Xcode 中选择 `File` -> `Open...` 打开当前项目目录即可。
