# Timer (倒计时应用)

基于 Swift & SwiftUI 构建的轻量级原生 macOS 倒计时单窗口应用。

## 规格与标识符规范

- **Bundle Identifier**:
  - Release 版：`com.hycity.timer`
  - Debug 版：`com.hycity.timer.debug`（数据独立隔离）

## 功能特性

- **清爽只读倒计时主界面**：
  - 主界面以 6 格数字卡片（2位时、2位分、2位秒）纯展示当前选中的倒计时，不干扰计时视图。
  - 底部提供 **开始 / 暂停 / 继续**、**重置** 与 **编辑** 三个按钮；倒计时结束时触发系统提示音与界面提醒。
- **独立弹窗新建与编辑**：
  - 点击侧边栏顶部的「新建倒计时」按钮、空界面按钮或快捷键 `⌘N` 打开「新建倒计时」弹窗；点击主界面「编辑」按钮或侧边栏右键菜单「编辑」打开「编辑倒计时」弹窗。
  - 弹窗内包含**名称输入框**（留空默认命名为“未命名倒计时”）与 **6 格可交互数字卡片**（支持点击聚焦、键盘数字连续输入自动跳格、方向键/退格键及鼠标悬浮上下箭头微调，并附带一键「归零」按钮）。
- **倒计时列表（侧边栏）**：
  - 窗口左侧为可折叠侧边栏（使用工具栏中的系统侧边栏按钮切换），列出所有倒计时项及其设定时长。
  - **空状态启动**：每次启动应用时默认不选中任何倒计时，右侧显示简洁的空状态引导界面；在左侧选择已有倒计时或新建倒计时后才进入倒计时主界面。
  - **切换与管理**：点击侧边栏项即可切换（若当前倒计时正在运行或已暂停，会先弹窗确认是否停止）；右键菜单支持「编辑」「删除」；选中后按 Delete 键也可删除（删除当前选中项会停止计时并回到空界面）；支持拖动排序。
- **单窗口**：应用仅允许一个主窗口（`⌘N` 用于在当前窗口内新建倒计时，不支持多开窗口）。

## 运行与开发

### 方式 1：打包并运行 macOS 原生应用（推荐）
```bash
# 构建 Release 版本 (输出 dist/Timer.app，系统自动本地化为“倒计时”)
./build_app.sh release
open dist/Timer.app

# 构建 Debug 版本 (输出 dist/Timer-Debug.app，系统自动本地化为“倒计时 (Debug)”，数据与 Release 完全隔离)
./build_app.sh debug
open dist/Timer-Debug.app

# 同时构建 Release 与 Debug 版本
./build_app.sh all
```

### 方式 2：终端命令行直接运行
```bash
swift run
```

### 方式 3：使用 Xcode 打开
```bash
xed .
```
或者在 Xcode 中选择 `File` -> `Open...` 打开当前项目目录即可。
