# Timer (倒计时应用)

基于 Swift & SwiftUI 构建的轻量级原生 macOS 倒计时单窗口应用。

## 规格与标识符规范

- **Bundle Identifier**: `com.hycity.timer`（规范推荐：采用**全小写**反向域名记法）。

## 功能特性

- **6 格数字倒计时**：
  - 时（2位）、分（2位）、秒（2位），清晰分隔并带有标签提示。
- **灵活输入与交互**：
  - 点击任意格子可直接键盘输入数字，输入后光标自动跳至下一格。
  - 鼠标悬浮格子时提供上下箭头快速微调（+1 / -1）。
- **运行控制**：
  - **开始 / 暂停 / 继续**：一键控制倒计时。
  - **重置 / 清空**：可一键重置至设定时长或清零。
  - **倒计时结束提示**：结束时触发系统提示音与界面提醒。

## 运行与开发

### 方式 1：终端命令行直接运行
```bash
# 运行
swift run

# 或编译构建
swift build
```

### 方式 2：使用 Xcode 打开
```bash
xed .
```
或者在 Xcode 中选择 `File` -> `Open...` 打开当前项目目录即可。
